## Scope

Change the review-begin adapter's PR context representation and its emitted,
agent and review-prompt guidance. The existing filesystem boundary observes
staged bytes, their length and SHA256, explicit absence or a shaped read error;
it does not decide admissibility. A positive existence check followed by an
ENOENT race, EACCES or another read failure is an unavailable observation,
not silent absence or an escaping host exception. Expose only a bounded safe
error code, not credential contents or arbitrary exception text. Add a small
pure `.cljc` context-custody law that validates the
reference shape and compares the admitted binding with each later observation.
The adapter retains that binding in the session, applies the law before later
stage/submission calls and reports refusal on mismatch. Return the observed
binding with those results and the submission so the pure invocation law can
independently reject a trace whose later context metadata differs from begin,
is missing, or reports a custody refusal. The trace check compares declared
observations; it cannot independently authenticate disk bytes or model reading.
The new compiled invocation verifier requires the custody protocol and explicit
context-source key on every admitted begin, including explicit nil for absence.
It never selects legacy validation from raw trace shape or a model claim.
This is an intentional new custody contract, not a context-consumption counter.
Extend the existing
compiled full-input verification with oversized serialized-response regression,
lossless bounded file readback, absence and changed/truncated-context controls.
Preserve the existing full-diff and review-stage law semantics and tool IDs,
input schemas, exposure,
permissions, complete diff and page assessment geometry.
