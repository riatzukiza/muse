## Outcome

A separately named, closed batched assessment operation accepts distinct page
IDs and individual model-authored judgments and binds each to actual delivered
source inside the owning producer and canonical native verifier. The model
does not act as a copier of already established offsets and hashes. Complete
final per-page assessments retain their original representation and custody.

## Scope

Describe the additional operation and its immutable source/host/session/read
bindings before implementation. Reuse current delivery, per-page assessment,
atomic refusal and native LAST laws. Keep the existing single-page operations
and strict batch request unchanged. A missing or mismatched hash/offset in the
old batch grammar must still refuse; never reinterpret a malformed old call as
the new grammar. Add the new operation explicitly to exposed tool shapes,
guarded orchestration and canonical native decoding/witness construction.

New arguments contain a bounded ordered vector of closed `{id,note}` members.
Trusted session pages supply geometry/digests/source; actual native events
supply call/part/position/membership witnesses. Derive those relationships from
real successful deliveries, including mixed single/batched reads, rather than
inventing calls or accepting model-supplied custody flags. A nonblank note for
every submitted ID remains mandatory; mechanically valid custody does not
establish substantive judgment. Preserve current whole-page read geometry,
read wire bytes and qualified host/read profile. Keep current cardinality4,
request16384B, note2048B, whole-response48000B/one-line and host51200B/2000-line
