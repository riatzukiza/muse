## Outcome

The actual compiled adapter returns a bounded staged-context reference and
retains a pure-law-validated binding. Later stage/submission calls refuse when
the observation no longer matches or cannot be obtained.

## Scope

The existing filesystem boundary reports bytes, length/hash, explicit absence
or shaped unavailable/read errors; policy stays in the pure law. Wire session
binding and refusal before adapter stage/submission transitions and writes.

## Non-goals

the character field/mood. This slice alone does not authorize downstream adoption.

## Acceptance criteria

1. Pure law controls cover a valid reference and explicit nil, malformed
   bindings, equality, byte/hash/path differences, presence changes and shaped
   errors. Absence is distinct from an unavailable observation.
2. The filesystem boundary shapes EACCES, another I/O failure and an exists/read
   ENOENT race. No arbitrary exception text or credentials enter the result.
   The law marks these inadmissible. Compiled adapter controls prove structured
   refusal before both a stage transition and a submission write.
3. Actual compiled begin references path/UTF8-byte length/SHA256, never the
   inline context body. Preserve staged Unicode/multiline bytes and recover the
   tail through bounded fixture reads. At the observed1482-page geometry, its
   serialized response is below49152bytes. Retain the clipped-response negative.
4. Changed, truncated, disappearing and newly appearing context refuses before
   later stage/submission effects. Results expose the observed binding or a
   structured custody refusal for the next story's trace checks.
5. Guidance requires the complete context before the first stage, checking
   read bounds/clipping and stopping without submission when recovery fails.
   Fixture transport/readback and declared metadata do not prove model assessment.
6. Existing tool IDs, argument schemas, exposure, permissions, complete diff and
   stage order remain unchanged. Relevant pure/compiled regression gates and
   lint pass with zero warnings. Preserve the entire owning epic's journal
   history and freeze the final qualified planning prefix before RED.

transport/law/adapter slice and its guidance/regressions; no second verifier
implementation or downstream source adoption is included.
